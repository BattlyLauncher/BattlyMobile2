# Remove Battly Mobile account data

Battly Mobile can store:

- Local/offline launcher profiles.
- Microsoft Minecraft accounts.
- Battly accounts.
- Launcher settings, controls and local game data stored in the app-owned Android folder.

To remove an account from the launcher:

1. Open the account selector.
2. Select the account you want to remove.
3. Press the delete/trash action.
4. Battly removes the local account entry from the device.

To remove local app data entirely, use Android system settings and clear Battly Mobile storage.

Microsoft account closure is handled by Microsoft:

https://aka.ms/CloseAccount

For Battly account deletion or privacy requests, use the account/data removal flow provided by Battly support or the Battly account website.
